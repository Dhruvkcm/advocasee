# Advocase

## Project Description

Advocase is a web-based Client and Case Management System developed for advocates, junior lawyers, and small law firms.

The application helps advocates manage clients and legal cases digitally through a clean and user-friendly interface.

---

## Version 1 Features

### Authentication

- Login
- Signup
- Logout

### Dashboard

- Total Clients
- Total Cases
- Recent Clients
- Recent Cases

### Client Management

- Add Client
- Edit Client
- Delete Client
- Search Client

### Case Management

- Add Case
- Edit Case
- Delete Case
- Search Case
